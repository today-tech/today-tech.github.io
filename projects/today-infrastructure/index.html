TODAY Infrastructure 是一套模块化 Java 应用框架。它把应用启动、依赖注入、Web MVC、Netty 和数据访问组织在可以阅读、组合和扩展的模块里。

应用基础设施

01 / THE IDEA

适合想知道
框架如何工作的人。

它适合希望深入理解 IoC、AOP、Bean 生命周期、Web MVC 和 Netty 如何协作的 Java 开发者，也适合想研究一套轻量、可读、可修改的应用基础设施的小型项目或个人开发者。

如果你的首要需求是成熟生态、广泛的第三方 Starter、商业支持或现成的企业级集成，Spring Boot 仍然是更稳妥的选择。TODAY Infrastructure 是独立的框架实践，不是 Spring Framework 或 Spring Boot 的二进制兼容替代品。
